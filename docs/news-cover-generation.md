# Обложки новостей titlo.ru

Источник правды для ленты кабинета: `lib/content/news.cabinet.ts` + файлы в `public/news/assets/cab-*.png` (+ `.webp`).

## Правило качества

Каждая новость из кабинета получает **уникальную** обложку.

**Запрещено:**

- копировать одну PNG из архива на несколько постов (как было с «АУДИТ САЙТА» на 5 карточках);
- клонировать одну сцену/подложку (одинаковые стикеры/стол) на все посты;
- ставить один `imageUrl` двум разным новостям;
- брать готовые архивные обложки с уже впечатанным текстом (`8860a3…`, `5add57…`, старый `cover-bg-08` и т.п.) и клеить сверху второй текстовый слой.

Стилистика = эталон старых обложек ленты:

| Референс | Метафора / палитра |
|----------|--------------------|
| `0247ae425fd7e0c5.png` | розовый планшет, search suggestions |
| `ee3dc0c8626abf92.png` | navy мониторинг / график |
| `f317eb262d7e2e64.png` | mint стикеры TLP |

Требования к кадру:

- тематическая lifestyle-сцена под модуль (не голый ноут);
- **своя** сцена и цветовая палитра на пост — чередовать метафоры как у референсов;
- крупный заголовок модуля слева сверху;
- тёмный бейдж слева снизу: модуль + уникальный подзаголовок.

## Основной путь (предпочтительный): полные концепт-обложки

1. `GenerateImage` — полная концепт-сцена с типографикой внутри кадра (как эталоны выше).
2. Пачками по 2, с разными метафорами/палитрами.
3. Установка в ассеты (1536×1024 PNG + webp) и замена `imageUrl` в `news.cabinet.ts`.

Пример установки одного файла:

```js
// key — стабильный id поста; hash → cab-<sha1-16>
// sharp: resize 1536×1024 cover → png; webp quality 90 width 1200
// заменить imageUrl у нужного индекса в lib/content/news.cabinet.ts
```

Имена файлов: `cab-<hash16>.png` / `.webp` в `public/news/assets/`.

После пачки проверить: число постов = число уникальных `imageUrl`, все PNG на диске.

## Запасной путь: cover-bg + SVG

Только если нет возможности генерировать полные концепты.

Скрипт: `scripts/sync-cabinet-news.mjs` (`npm run sync:cabinet-news`), оверлей: `scripts/regen-cabinet-covers.mjs`.

1. Фон — из пула **чистых** фото `public/news/assets/cover-bg-*.jpg` (без типографики).
2. На каждый `id`: свой кроп/тон + SVG-оверлей (label + tag + subtitle).
3. Выход: `cab-<hash>.png` + `.webp`.

Хеш включает `id` + label + subtitle → разные посты не получают один файл.

Новые `cover-bg-NN.jpg`: 1536×1024, без текста/водяных знаков. Дописать в `COVER_BGS` в `sync-cabinet-news.mjs`. Не использовать фоны с впечатанной типографикой.

```bash
npm run sync:cabinet-news
node scripts/regen-cabinet-covers.mjs 0 2   # посты 1–2
node scripts/regen-cabinet-covers.mjs 2 2   # посты 3–4
```

## Новые cab-новости

При синке нового поста из кабинета:

1. Не переиспользовать соседний `cab-*`.
2. Сгенерировать **новую** концепт-обложку (или запасной cover-bg+SVG с новым hash).
3. Добавить png/webp и прописать `imageUrl` только у этого поста.
4. Smoke: `/news/` — карточки визуально разные, без повторяющихся подложек.
