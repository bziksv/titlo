# Подбор слов Wordstat — changelog

## 1.0.0 — этап 1
- Таблицы проектов, групп, фраз, запусков, пресетов, журнала запросов; модели и связи.
- Настройки пресета: регион, устройства, глубина, `left_limit` (по умолчанию 200, 1–2 000), минус-слова.
- Разбор списка фраз: нормализация, дубли, лимиты (≤ 400 символов, ≤ 7 слов).
- Оценка запросов до старта: число обращений к API с учётом глубины.
- Клиент Wordstat (`wordstat/json`, `pagetype=words`, левая и правая колонки) и лимит частоты `wordstat_rps` (по умолчанию 5).
- Фоновый сбор с глубиной: очередь `wordstat`, прогресс запуска, отмена, повторы.
- Пункт меню и право `Wordstat keywords`, маршруты `pages.wordstat-keywords.*`.
- Пресеты, массовые действия с фразами, переименование/слияние/удаление групп, экспорт XLSX.
- Интерфейс: список проектов, карточка проекта, таблица фраз без перезагрузки, Select2 для регионов и пресетов.
- Очередь и деплой: supervisor-группа `cabinet-titlo-wordstat` (`numprocs=2`), рестарт в `deploy-titlo.sh`, запись в реестре провайдеров `config/cabinet-xml-providers.php`.
